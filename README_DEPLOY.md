# 🚀 دليل رفع وتحديث السيرفر على Render.com (الإصدار الاحترافي v2.3 + نظام الرسائل SMS + حماية PIN)

هذا المجلد يحتوي على كافة الملفات الجاهزة والمحدثة بالكامل لرفعها مباشرة على حسابك في **Render.com** لتحديث السيرفر:
`https://relay1-tdgn.onrender.com/`

---

## 📁 محتويات المجلد:
1. **`dashboard.html`**: لوحة المراقبة والتحكم الاحترافية الجديدة، محمية برقم سري مشفر لا يظهر لأحد (`527149`)، وتتضمن مراقبة الهواتف الطرفية والتحويلات الداخلية المتاحة لحظياً، وإدارة رسائل SMS، وتدعم التثبيت كتطبيق PWA.
2. **`server.js`**: خادم الوسيط السحابي (Node.js WebSocket Broker) مع دعم الاتصال الداخلي المباشر بين الهواتف الطرفية (Intercom / PBX Extensions مثل #101 و #102)، وترحيل SMS، وخدمة ملفات PWA، وميزة **Keep-Alive الذاتي 24/7** لمنع خادم Render المجاني من النوم نهائياً.
3. **`index.html`**: الهاتف الطرفي الافتراضي عبر الويب (Web Remote Phone) المحدث برقم تحويلة مخصص لكل طرفي (مثلاً `#101` أو `#102`)، مع إمكانية الاتصال المباشر بين الهواتف الطرفية بالصوت عالي الدقة HD ثنائي الاتجاه، ودليل مباشر للتحويلات المتصلة.
4. **`manifest.json` & `sw.js` & `icon-192.png` & `icon-512.png`**: ملفات تطبيق الويب التقدمي (PWA) لتحويل المتصفح إلى تطبيق جوال أصيل بدون متجر.
5. **`package.json`**: ملف تعريف الحزمة والاعتماديات (`ws`) وأمر التشغيل `npm start`.
6. **`GSM-Cloud-Relay-Gateway-v2.3.apk`**: تطبيق الأندرويد المحدث للهاتف الوسيط (إصدار 2.3) منظف من الأذونات الحساسة وغير المقبولة لتجاوز حظر التثبيت في أندرويد.

## 🛠️ خطوات التحديث على Render.com:

### الطريقة الأولى (عبر مستودع GitHub المرتبط بـ Render - الطريقة الموصى بها):
1. افتح مجلد المستودع (Repository) الخاص بك على جهازك والذي ربطته بسيرفر Render.
2. انسخ جميع الملفات من هذا المجلد (`DEPLOY_TO_RENDER`) واستبدل الملفات القديمة بها:
   - `dashboard.html`
   - `server.js`
   - `index.html`
   - `package.json`
   - `GSM-Cloud-Relay-Gateway-v2.3.apk`
3. افتح سطر الأوامر (Terminal / Git Bash) داخل مجلد المستودع ونفذ الأوامر التالية:
   ```bash
   git add .
   git commit -m "Update v2.3: Protected Dashboard PIN 527149, SMS Relay, and APK v2.3"
   git push origin main
   ```
   *(أو `git push origin master` حسب اسم الفرع)*
4. سيقوم موقع Render فوراً باكتشاف التحديث وبناء السيرفر الجديد خلال أقل من دقيقة.
